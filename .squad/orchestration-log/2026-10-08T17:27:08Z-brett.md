## Key Decisions Committed

1. **Digest-only, no fallback.** Server-side acceptance unverified; first real run answers it. See compatibility.md B9a.

2. **Verify by read-back, never assume.** After creating each version, read it back and assert policy and image match exactly. Detects silent failures (e.g., Enforced agent whose policy did not attach looks identical to one that allows everything).

3. **Idempotent on pod restart.** Version matching image digest AND policy ARM id, not in terminal bad state, is reused. Existing versions never mutated (maintains auditability). A restart creates nothing and exits 0.

4. **Deploy venv isolation.** One image, two venvs; agent's model stack untouched by deployer's dependencies. Critical to containment demo's control (image digest is the experiment variable).

5. **Only `DEMO_POLICY_MODE` differs between agents.** Evidence label only, nothing branches on it. `assert_single_variable` and `test_environment_differs_only_by_the_evidence_label` enforce this.

6. **Timeouts are bounded and a timeout is a failure.** No container-start equivalent in SDK; version still "creating" at deadline is failure, not pass. An unprovisioned agent proves nothing.
