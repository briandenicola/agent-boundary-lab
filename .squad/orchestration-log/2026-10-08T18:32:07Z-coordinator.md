## Defect B: Hardcoded Fallback Image Digest (Control Variable Drift)

**Finding:** Parker had hardcoded a fallback image digest used whenever `AGENT_IMAGE_DIGEST` was unset. The digest is the experiment's control variable, and a stale fallback would deploy code that was not what was built. The infrastructure plan would look identical, but the running image would be wrong — a critical defect in containment testing.

**Fix:** Resolve the digest live from ACR at apply time; fail if absent. Added shared `arm:_acr-digest` task to look up the digest in one place. Also routed `build:agent-digest` through this task because it was capturing `az ... -o tsv` straight into a variable — this is the **fourth instance** of the az auto-upgrade chatter bug class (see Decision #30 below).

**Context:** The experiment's control is the image digest. A fallback to stale code would invalidate containment claims. Live resolution with hard failure on absence is mandatory.
