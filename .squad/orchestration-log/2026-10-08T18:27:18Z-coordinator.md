## Defect A: Leftover-Placeholder Guard Ran on Unsubstituted Source

**Finding:** The guard re-ran `kustomize build` on the `UNSUBSTITUTED` source, so it counted all 34 placeholders every run, could never fail, and printed "rendered 34 placeholders" as though it had passed. It also ran **AFTER** `kubectl apply`, allowing an apply with unsubstituted placeholders.

**Fix:** Render once into a variable, check that rendered stream, and refuse before applying. The check now precedes the apply, and the guard validates the actual stream that will be sent to the API server.

**Context:** This defect would have allowed phantom "renders 34 placeholders" messages on every run and silently applied secrets/config with placeholder values intact.
