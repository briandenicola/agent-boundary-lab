## Key Decisions Committed

1. **Exit codes are the contract:** `0` pass, `1` fail, `2` inconclusive + not_implemented. Anything consuming this must not treat 2 as success.

2. **Endpoints never hardcoded.** Resolution: `DEMO_POLICY_API_URL` / `DEMO_TEST_RECEIVER_URL` env vars, fallback to `terraform -chdir=infra/cloud output -raw`. Unresolvable → inconclusive, nothing attempted.

3. **Section A reports two roll-ups:**
   - Endpoint transport baseline (A1–A5): PASS
   - Receipt-log retrievability (A6): PASS (once Lambert verified table names)
   - Overall: PASS

4. **A5 is hard gate on attribution:** If test receiver ever grows auth (401/403/407), a 403 from inside sandbox stops being attributable to egress policy. Demo design changes. **Parker: do not put authentication or IP restriction in front of test receiver.**

5. **Never probe without the run marker.** An unmarked baseline POST plants unattributable receipt on every run, manufacturing the exact ambiguity A7 detects. Marker is not a credential; it is the experiment's traceability.

6. **Bound log queries with explicit (start, end), never "last N minutes".** Padded windows reach back before run started, let previous run's traffic answer this run's question. Padding is contamination, not caution.

7. **An unattributed arrival outranks a healthy pipeline.** Working log does not make unattributable row attributable. Receipt absence has four outcomes, not two.
