# Demo UI goes through A2A; run ids need the verbatim-records prompt
Facade run ids were empty because the agent returns tool records only when the prompt asks for them verbatim (invoke.DEFAULT_PROMPT); ResponsesTarget already parsed them the same way. Callers (a2a client, UI) now send that prompt; the facade stays a passthrough. UI now calls each slot's facade as an A2A client (ui_a2a.py), imports no Azure SDK, direct invoke path removed (nothing required it). UI role/identity left as is (now unused for Foundry). The UI image no longer needs azure-ai-projects. Facade image not rebuilt for the client.send signature change (UI does not use the facade image's client).
