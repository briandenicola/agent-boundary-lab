# A2A facade is the supported route for A2A over hosted agents
Native hosted A2A is unsupported (B5d). Built `containment_demo.a2a_facade` (core / server / target): A2A layer imports no Foundry; `ResponsesTarget` is the only Foundry code and reuses invoke's path with store=False. Two ClusterIP deployments from one image differing only by target env, reusing the demo-ui ServiceAccount (no new identity). Shared-token auth behind an Authenticator seam for issue #4. protobuf must stay <7 for a2a-sdk 1.0.2. Wording: "hosted agents are invoked through Responses; the facade exposes them as A2A". Native A2A on audit is switched off via `cloud:a2a-disable` (not yet run). All PROPOSED/UNVERIFIED until deployed.
